# Singapore COVID-19 Data Analysis

## Description
A C++ program that reads Singapore COVID-19
data from a CSV file.

## Features
- CSV file reading
- CSV tokenisation
- Data type conversion
- Exception handling
- Object-oriented programming
- Vector storage
- Summary statistics

## Requirements
- C++17
- GCC compiler

## Compile
g++ -std=c++17 -Iinclude src/main.cpp src/CovidRecord.cpp src/CsvReader.cpp -o build/covid_reader.exe

## Run
./build/covid_reader.exe
